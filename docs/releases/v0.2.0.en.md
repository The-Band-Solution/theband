## The process defect this release left behind

**The PR came from `release/v0.2.0`, not from `development`.** The version bump
never made it back to the integration branch: `development` kept `0.1.0` in
`mix.exs` while production served `0.2.0` — the single source of the version asserting
what the environment contradicted.

Discovered in the back-merge of [#646](https://github.com/The-Band-Solution/theband/pull/646),
which separated the eight false conflicts (identical content on both sides) from the only
real difference (one line). It became a rule in [README.md](README.md) and an amendment to
lesson L83: **the bump is a commit on `development`**, before opening the release PR.
